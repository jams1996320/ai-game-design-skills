# 游戏素材制作｜员工使用说明

用 Codex 帮你整理游戏方案、编写即梦提示词，并把视频变成去掉背景的 PNG 图片序列。

## 第一次使用

1. 使用公司准备好的 **Windows 电脑**，打开并登录 **Codex**。没有安装或无法登录时，联系负责人。
2. [点击下载文件包](https://github.com/jams1996320/ai-game-design-skills/archive/refs/heads/master.zip)。下载后右键选择 **“全部解压缩”**，不要直接在压缩包里操作。
3. 在 Codex 中打开解压后的 **`ai-game-design-skills-master` 文件夹**。选到能看到本说明文件的那一层。

下面只做你需要的步骤。**已经有即梦视频，可以直接从第 3 步开始。**

## 1. 整理游戏想法

把下面这段话复制到 Codex，把最后一句换成你的想法：

```text
使用 $game-design-decision，帮我整理游戏方案。
我的想法是：……
```

## 2. 生成即梦提示词

方案确认后，在同一个对话中发送：

```text
使用 $game-animation-seedance，根据刚才确认的方案，给我可以直接复制到即梦的提示词和操作说明。
```

按说明在即梦生成视频，并下载到电脑。视频应使用纯色背景，人物、服装和道具颜色不要与背景相同。

## 3. 视频去背景，生成图片序列

把视频复制到刚才解压的文件夹中，然后向 Codex 发送以下文字，把 `我的视频.mp4` 换成实际文件名：

```text
使用 $game-video-to-png。
请处理文件夹里的“我的视频.mp4”，自动准备所需工具、识别背景色并去掉背景。
完成后请打开效果预览，并告诉我结果保存在哪里。
```

第一次处理需要联网下载工具，请等待。无需自己安装其他软件或输入命令；遇到授权提示，先看 Codex 说明。

## 4. 检查结果

播放预览，检查人物和道具是否完整、边缘是否干净。有问题时暂停，记下画面显示的帧号，直接告诉 Codex，例如：

```text
第 35 到 42 帧衣服有缺失，第 78 帧边缘有残色。请修复这些帧，保留旧版本，再打开预览给我检查。
```

确认没有问题后，把 Codex 提供的 **`frames.zip`** 交给负责人。这就是去掉背景后的 PNG 图片序列。

**遇到报错：**把报错文字或截图发在当前 Codex 对话中，说“请帮我检查并处理”；仍无法解决时联系负责人，不需要自己修改电脑设置。

> 当前为测试版：已完成 macOS 合成视频测试，Windows 安装和真实即梦视频效果仍需试用确认。
