# 游戏素材制作

打开公司已配置好的 Codex，按下面的示例发送消息即可。下载文件、准备工具和整理结果由 Codex 处理，无需自己安装软件或输入命令。

**请尽量在同一个对话中继续。已有即梦视频，可以直接从“处理视频”开始。**

## 第一次使用

把下面这段话发给 Codex：

```text
请读取这个仓库：
https://github.com/jams1996320/ai-game-design-skills

把需要的文件下载到当前工作目录，读取对应的 SKILL.md，并按其中的流程帮我完成后续任务。
我是 Windows 用户，不熟悉软件操作，请直接帮我执行；需要我提供素材或确认时再告诉我。
```

## 整理游戏想法

```text
我想做一个这样的游戏：……
请使用仓库里的游戏设计流程，帮我整理方案。
```

## 准备即梦素材

方案确认后，继续发送：

```text
按刚才确认的方案，帮我准备即梦提示词和需要的参考素材。
```

即梦视频生成仍按现有方式完成。拿到视频后回到这个对话继续；背景应为纯色，人物、服装和道具颜色不要与背景相同。

## 处理视频

在对话中提供视频；如果无法添加视频，告诉 Codex 视频在电脑上的完整路径，无需移动文件。然后发送：

```text
请把这个视频去掉背景，输出透明 PNG 图片序列。
自动准备所需工具并识别背景色，完成后在这里给我效果预览和结果文件链接。
```

首次处理可能需要等待工具下载。出现授权提示时，按 Codex 的说明确认。

## 审核和修改

查看 Codex 提供的预览。有问题直接回复，可以附截图；能看清帧号时一起提供：

```text
第 35 到 42 帧衣服有缺失，第 78 帧边缘有残色。
请修复这些位置，保留旧版本，再给我预览。
```

没有问题就回复：

```text
审核通过，请整理最终文件，给我下载链接和交付说明。
```

## 遇到问题

直接在当前对话中说“请帮我检查并处理”，并提供报错文字或截图。不需要自己修改电脑设置；Codex 无法处理时再联系负责人。

> 当前为测试版：Windows 安装和真实即梦素材效果仍需试用确认。Codex 无法打开、登录或没有必要权限时，请联系负责人。
